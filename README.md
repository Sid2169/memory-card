# Memory Card

A picture memory game built with React, Vite, and plain CSS for
[The Odin Project](https://www.theodinproject.com/lessons/node-path-react-new-memory-card).

**[Play the game](https://sid2169.github.io/memory-card/)**

## How to play

Pick each picture once as the cards shuffle. A repeat ends the round; selecting
every picture wins. Choose Easy (6 cards), Medium (9), or Hard (13). Best scores
are saved per difficulty in your browser.

Uses 13 local pictures, displayed without cropping. Supports mobile layouts and
keyboard controls.

## Development

Use Node.js 22.12+.

```bash
npm ci
npm run dev
```

Run `npm test`, `npm run lint`, and `npm run build` to check the project.
Pushes to `main` automatically deploy to GitHub Pages.
